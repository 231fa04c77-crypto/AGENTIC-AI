## 1. PharmaSync — Connect Pharmacy (Steps 2–3)

Hospital registration already existed. Today we implemented **Add Pharmacy → Connect with PharmaSync**.

### What it does

1. Hospital Dean opens **Pharmacies** → **Add Pharmacy**
2. Enters pharmacy name, manager, email, phone, license, address
3. Clicks **Connect with PharmaSync**
4. MedClues calls PharmaSync `POST /api/integration/pharmacies`
5. Stores returned `pharmacyId` as `partner_pharmacy_ref` with status `connected`

## 2. Health Community (Phases 1–3)

Built a full authenticated **medical knowledge Q&A** platform (not social media).

Architecture doc: [HEALTH_COMMUNITY_PLATFORM.md](./HEALTH_COMMUNITY_PLATFORM.md)

### Product flow

```
Patient asks → AI/rules moderation → Doctors answer
→ Searchable knowledge base → Book appointment CTA
```

### Phase 1 — MVP

- DB: questions, answers, bookmarks, reports
- Patient APIs: feed, search, ask, follow-up, my questions, saved, report
- Doctor APIs: feed, answer, edit, resolve, recategorize, recommend consult/ER

- Doctor community stats
- Dean hospital-scoped moderation

- Community Plus (5 questions/day; activate endpoint — payment later)
- Postgres full-text search (`tsvector`)

## 6. Enterprise scalability remediations (Phase 1 + Redis foundation)

Implemented critical fixes from the audit (not report-only):

| Fix | Detail |
|-----|--------|
| Transactional slot claim | `claim_slot_by_id` / `claim_first_available_in_block` hold `FOR UPDATE` in one TX |
| Queue tokens | `pg_advisory_xact_lock` + `MAX(token)+1` in one TX |
| DB pool | `DB_POOL_MIN` / `DB_POOL_MAX` (default 2–20) |
| 500 errors | Tracebacks only when `DEBUG=true` |
| Dispatch JWT | Uses `OPERATOR_JWT_SECRET` / `JWT_SECRET`; rejects insecure default in prod |
| Socket.IO | JWT required for room joins; optional Redis adapter via `REDIS_URL` |
| Payment WS | Requires JWT + appointment ownership |
| Dean cancel | Hospital isolation via doctor ownership |
| Uploads | Size/MIME limits + Cloudinary via `asyncio.to_thread` |
| List APIs | Default pagination caps on appointments/doctors |
| OTP / rate limits | Redis when `REDIS_URL` set; in-memory fallback |
| Webhook retries | `FOR UPDATE SKIP LOCKED` claim |

Load harnesses: `fastapi_back/scripts/load/`  
Set `REDIS_URL` for multi-instance readiness.
